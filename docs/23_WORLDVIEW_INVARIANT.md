# Мировоззрение как инвариант MAWorld — «любой цикл начинается от глобального»

Зашито в код (не только в доку) как `libs/maworld_core/global_cycle.py`, на котором сидят trace-bridge
и agents-runner. Источник — канон ContinuityOS.

## Две грани (обе enforced структурно, 9/9)
1. **Top-down каскад.** Любой цикл ОБЯЗАН открыться на `GLOBAL` и спускаться по одному уровню:
   `GLOBAL → STRATEGIC → TACTICAL → EXECUTION`. Нельзя рутить цикл с тактики/исполнения, нельзя
   перепрыгивать уровни, EXECUTION терминален. Аномалии/сигналы — это ВХОД, не корень цикла.
2. **Фрактал (самоподобие).** Каждый узел несёт отражение целого: неизменный `worldview`-хеш + id
   глобального объектива. «Каждый узел содержит отражение целого» — потеря отражения → цикл невалиден.

## Где это в каноне ContinuityOS (найдено)
- `00_CANON/HUMAN_CANON.md:56` — основной рабочий цикл **Изучение → Создание → Деплой → Интеграция**
  (старт с изучения системы целиком).

  обратная связь → изменение стратегии` + «Стратегические циклы» гейтят нижние.

  state`), потом сужение до next irreversible action.
- Фрактальный принцип (архив-канон): «Архитектура как фрактал; каждый узел содержит отражение целого —
  самоподобие, цикличность, идентичность, память».
- `mind/MIND_ARCHITECTURE.md:30` — CTHA-порядок `C(идентичность) → A → H → T`: глобальные константы
  отсекают первыми.

## Где зашито в MAWorld
| Модуль | Как применяет инвариант | Тест |
|---|---|---|
| `libs/maworld_core/global_cycle` | `open_global()` — единственный способ рутить цикл; `derive()` спускает на 1 уровень; `validate_chain()` ловит level-skip / потерю отражения | 9/9 |
| `services/trace-bridge` | каждый trace рутится GLOBAL-спаном, спаны каскадят вниз, несут `global_objective_id` (фрактал); cost-per-verified-outcome = spend/accepted | 9/9 |
| `agents/runner` | каждый цикл агента стартует с GLOBAL и каскадит; агент proposal-only (CTHA boundary — нет execute/gate/ledger/capability); challenger = dialectic | 9/9 |

## Инвариант (одной строкой)
Всё, что делает MAWorld, разворачивается сверху вниз из глобального объектива, и каждый узел цикла
обязан нести отражение целого. Authority при этом остаётся у детерминированного spine — инвариант задаёт
ФОРМУ цикла, не полномочия.

Полный adversarial-прогон после зашивки: **13/13 suites, 123 проверки** (`tests/run_all.py`).
