# incoming/ — карантин для существующих модулей

Кидай сюда любые свои наработки (в подпапках, как есть, в хаосе — нормально).
Правила разбора (делает Claude + владелец):
1. Модуль читается, классифицируется по MODULE_MAP слоту.
2. Проверяется на инварианты (README корня): float64 в деньгах? прямые side effects мимо гейта? LLM владеет состоянием?
3. Адаптируется под контракты из contracts/ и переносится в слот. Оригинал остаётся тут до подтверждения.
4. MODULE_MAP.md обновляется: CANDIDATE → WIP → DONE.
Ничего из incoming/ не запускается в прод напрямую.
